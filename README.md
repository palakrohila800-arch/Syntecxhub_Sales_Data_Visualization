# Syntecxhub Sales Data Visualization

## Project Overview

This project is created as part of the Syntecxhub Data Science Internship.

The project focuses on analyzing sales data and presenting the results using different visualization techniques.

## Objectives

- Analyze sales trends over time
- Calculate monthly and quarterly sales
- Compare sales across different categories
- Visualize category-wise sales share
- Present data using clear and understandable charts

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Google Colab

## Visualizations

The project includes:

1. Sales Over Time - Line Chart
2. Monthly Sales - Bar Chart
3. Category-wise Sales - Bar Chart
4. Sales Share by Category - Pie Chart

## Key Findings

- Sales fluctuate across the given period.
- June recorded the highest sales in the dataset.
- Electronics generated the highest total sales among the categories.
- Bar charts were used to compare monthly and category-wise sales.
- A pie chart was used to represent the sales share of each category.
